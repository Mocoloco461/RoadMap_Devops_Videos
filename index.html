מסלול לימוד רשתות ותשתיות DevOps

כל שלב כולל תקציר נושאים כדי להבין מהר מה תלמדו בכל סט סרטונים.

בחר קטגוריה

שלב 1 · יסודות רשת
מושגי בסיס ותשתית רשת

מתחילים מהיסודות שעליהם נשען כל עולם ה‑DevOps.

  • LAN / WAN וסוגי רשתות
  • IP, Subnet, Gateway, MAC
  • Hub, Switch, Router
שלב 2 · פרוטוקולים ושירותים
איך מידע זורם ברשת

הבנה של חוקי התקשורת והשירותים המרכזיים באינטרנט.

  • TCP/UDP ו‑Packets
  • DNS, DHCP, NAT, ARP
  • HTTP/S, SSL/TLS
שלב 3 · כלי אבחון
שליטה בפקודות רשת

לומדים לבדוק תקלות ולנתח חיבוריות כמו אנשי תשתיות.

  • CLI בסיסי ב‑Windows
  • PING, TRACERT, NETSTAT
  • IPCONFIG ואבחון תקשורת
שלב 4 · אבטחת רשת
הגנה, פרטיות והקשחת תשתיות

עקרונות אבטחה שכל איש DevOps ותשתיות חייב להכיר.

  • Firewall, VPN, IPsec
  • Proxy ו‑Reverse Proxy
  • DMZ והיכרות עם DDoS
שלב 5 · שרתים וענן
תשתיות חישוב, אחסון וירטואליזציה

המעבר מעולם הרשתות לסביבת Production מודרנית.

  • שרתים ו‑Virtualization
  • Containers מול VM
  • Cloud, RAID, NAS/SAN
שלב 6 · ארכיטקטורה מתקדמת
סקיילינג ותכנון רשת מתקדם

נושאים שמכינים אתכם לעבודה בסביבות גדולות ומורכבות.

  • CDN, VPC ו‑VLAN
  • Routing Tables
  • Spanning Tree ותכנון Segmentation
